Gap Identified
Network devices continuously exchange data in the form of packets.
Heuristic-based systems can provide fast and understandable detection, but predefined rules may not identify new or sophisticated attacks.
Machine-learning-based systems can detect abnormal traffic patterns, but they require datasets, model training and parameter tuning.
Some anomaly-detection approaches can identify unusual traffic but may not clearly explain why the traffic was considered suspicious.
There is a need for a lightweight, real-time and user-friendly monitoring system that combines traffic analysis, multiple detection rules, risk assessment and clear visualization.
From Detection
to Understanding
Existing methods detect threats, but practical, explainable monitoring remains a challenge.

Proposed Solution
Real-time Network Monitoring – Continuously monitor live network traffic.
Packet Capture – Capture network packets using Python and 
Scapy
.
Packet Analysis – Extract source/destination IP, ports, protocol, packet size and other relevant information.
Traffic Classification – Identify protocols such as TCP, UDP, DNS and IP.
Intrusion Detection – Detect suspicious activities using predefined detection rules.
Attack Detection – Identify patterns such as SYN Flood, Port Scanning, Suspicious DNS Requests , Suspicious Payloads, Malformed Packets etc.
Alert Generation – Generate alerts when suspicious behavior crosses defined thresholds.
Real-time Dashboard – Display traffic statistics, detected threats, alerts and host activity.
Data Logging – Store packet information and detected events for later analysis.

Module Description
Frontend UI : Provides a simple and responsive interface for monitoring network activity, viewing alerts, and accessing system reports.
Network Monitoring Module : Captures live network packets using Python and 
Scapy
 and continuously monitors network traffic.
Packet Analysis & Intrusion Detection Module : Processes packets, extracts relevant features, and detects suspicious activities using predefined detection rules.
Alert & Reporting Module : Generates security alerts, records detected incidents and risk levels, and provides historical reports.
Dashboard / Visualization Module : Displays real-time network traffic, protocol statistics, detected attacks, alerts, and host risk information.
Storage Module : Stores packet summaries, alert logs, and captured raw packets for later analysis and investigation.
